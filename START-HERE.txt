SAKE OF HEALTH — UNIFIED PLATFORM (complete build)

This folder is the whole project, ready to run on Windows: online shop, central admin, B2B
retailer/distributor portals, supplier & manufacturer portal, ERP (inventory ledger, approvals,
notifications), online shop stock, events & counter sales, field app with offline queue, locations,
central customers, manufacturers & manufacturing (orders, bills of materials, batch QC release),
and trade deliveries (shipments, challans, proof of delivery, driver app). The packages it needs are already included (node_modules), so no download is needed.
Needs: Node.js 20.6 or newer — 22 recommended (https://nodejs.org) — and, for the business platform, MySQL 8.

NEW IN THIS BUILD (2026-11-19)
────────────────────────────────────────────────────────────────────────────
  • The four shop products are permanently protected by the server itself. They cannot be
    deleted, switched off, renamed or duplicated by anything: admin, import, bulk change, sync,
    seed, restore. Every edit needs a reason and is logged (who, when, before/after).
    Production will not start if they are damaged.
    Check them any time: npm run verify:products
    Details: docs\unified\PROTECTED-PRODUCTS.md
  • Settings: every variable is in docs\unified\ENVIRONMENT.md. Use these commands:
      npm run setup       creates your .env with new secrets
      npm run check:env   lists what is missing; it never shows values
      npm run secrets     prints new random secrets
    In production the app stops with a clear list if a required setting is missing or unsafe.
  • Hostinger Business: background work now runs from a Hostinger Cron Job
    (scripts\cron\run-jobs.js, every 5 minutes). Business documents can stay in the private folder
    or go to an S3-compatible bucket. See docs\DEPLOYMENT-HOSTINGER.md and
    docs\unified\BACKGROUND-JOBS.md.
  • Price list and invoice reconciliation (read-only; nothing imported):
    docs\reconciliation\README.md — it lists the decisions it needs from you.
  • Release gate: node scripts\release-gate.js. Deploy only when it says RELEASE ALLOWED.

2. RUN THE MYSQL 8 TESTS (10–20 minutes) — this is what finishes validation
────────────────────────────────────────────────────────────────────────────
  a) Create the throw-away test database once — docs\unified\SETUP-AND-TEST-ON-WINDOWS.txt,
     step A4 (database sakeofhealth_test, account soh_test; it must hold nothing else).
  b) In PowerShell, in this folder:
       $env:TEST_DB_HOST = "127.0.0.1"
       $env:TEST_DB_USER = "soh_test"
       $env:TEST_DB_NAME = "sakeofhealth_test"
       .\RUN-ALL-TESTS.cmd --mysql
     (type the soh_test password when asked; it is hidden and never saved)
  c) Zip the test-results folder and send it back. Do not edit tests to make them pass.
  The test runner refuses production, any database not ending in _test, root, and any account
  with rights outside the test database.
