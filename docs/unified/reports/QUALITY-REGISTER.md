# Quality register — 19 November 2026

Defects found during this phase. Earlier phases have their own registers: `docs/phase-0.5/`, `docs/phase-1/`
and `docs/unified/DELIVERY-REPORT.md`.

How to read the table:

- **Severity:** Critical = data loss or a total failure of a required function; High = a security weakness, or a required function that does not work on the target hosting; Medium = wrong or degraded behaviour with a workaround; Low = cosmetic or tooling.
- **"PASS (no DB)":** the test ran and passed here, without a database.
- **"NOT RUN — MySQL":** the test is written but could not run, because no MySQL 8 server was available. It runs in CI and with `node scripts/release-gate.js`.
